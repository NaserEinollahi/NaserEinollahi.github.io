# Naser Einollahi — Academic Website

Static one-page academic portfolio for GitHub Pages.

## Publish
Upload `index.html`, `style.css`, and `script.js` to the root of the `main` branch of `NaserEinollahi/NaserEinollahi.github.io`.

GitHub Pages should then serve the site at `https://nasereinollahi.github.io/`.
